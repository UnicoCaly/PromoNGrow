## 1. Origins

### The PrintCo Era
Promo & Grow descends from a 20-year print and production business originally operating as **PrintCo Direct**. PrintCo was a commodity signage vendor — banners, vehicle wraps, trade show displays — serving a broad base of small businesses across Southern California. The business was profitable but undifferentiated, competing primarily on price against Vistaprint, 4over resellers, and local print shops.

### The Proágo Transition
In 2025–2026, Carlos repositioned the parent operation from PrintCo Direct to **Proágo Branding Dept.** — a brand infrastructure studio targeting $30K–$120K private club engagements. The flagship client is Virginia Country Club (12+ year relationship, 53-page brand infrastructure system, 750 Signature edition calendars annually). This repositioning created a strategic problem: commodity print jobs and $500 tent orders didn't belong under the Proágo name.

### Promo & Grow as a Separate Entity
**Promo & Grow** (promongrow.com) was created as the billing and fulfillment layer for transactional print sales — specifically custom event displays. The purpose is threefold:

1. **Revenue segmentation** — keep commodity print revenue off the Proágo books and brand
2. **Client base separation** — small business event buyers vs. private club decision-makers
3. **Passive income vehicle** — build toward automated order processing and minimal-touch fulfillment

## 2. Business Model

### Revenue Model
P&G is a **custom print reseller** with production handled by third-party vendors:
- **B2Sign** — primary vendor for tents, displays, and fabric products
- **4over** — secondary vendor with API integration potential for automated order processing

- **Typical markup:** 2.5–3x (60–67% gross margin)
- **Average order value:** ~$350 (Shopify), higher for phone/quote orders
- **Cost of goods:** Vendor production + shipping
- **Operating cost:** Near-zero (no employees, no rent beyond existing Proágo space)

### Revenue Targets
- **Bridge revenue:** P&G exists to fund the Proágo transition, not replace it
- **Passive income goal:** Scale from ~$2K/month autopilot to $5–8K/month with reactivation, ads, and automation
- **Not the priority:** Proágo club engagements ($20K–$120K) remain the primary business. P&G is the engine that keeps the lights on while those close.

### Fulfillment Flow (Current)
1. Client places order on promongrow.com or emails/calls
2. Carlos reviews artwork files manually
3. Carlos places production order with B2Sign or 4over
4. Product ships to client directly or to Lynwood for pickup
5. Average turnaround: 5 business days

### Fulfillment Flow (Target — Phase 3)
1. Client orders on site → uploads artwork
2. AI file checker reviews artwork automatically (Claude API)
3. Approved files route to 4over via API for production
4. 4over ships directly to client (drop-ship)
5. Carlos only intervenes on exceptions
6. Average turnaround: 5 business days, near-zero touch

## 14. Integration Roadmap — Client Artwork System

### Problem Statement
The #1 operational bottleneck at P&G is back-and-forth on client artwork files. Based on 20 years of production experience, the most common file issues are (ranked by frequency):

1. **No bleed / wrong dimensions** — client submits a file that doesn't match the product template
2. **Amateur design / bad layout** — text too close to edges, empty areas, poor composition
3. **Wrong resolution (too low DPI)** — 72dpi web graphics submitted for large-format print
4. **RGB instead of CMYK** — colors shift during production
5. **Wrong file format entirely** — Word docs, low-res screenshots, etc.

Each bad file submission creates a manual review-and-reply cycle that takes 15–30 minutes of Carlos's time. At scale, this is the single biggest barrier to P&G operating passively.

### Solution Architecture — Three Phases

The system is designed to progressively eliminate file issues from 40% (Phase 1) to 90%+ (Phase 3), with each phase building on the previous one.

---

### Phase 1 — Design Resources Page
**Timeline:** Launch with site (Week 1–2)
**Cost:** $0
**Technical complexity:** Zero code — static Shopify page
**Impact:** Eliminates 40–50% of bad file submissions

#### What it includes:
- **File requirements reference** — accepted formats (PDF, AI, EPS, PNG, PSD, JPG), resolution specs (300 DPI minimum, 150 DPI for items over 48"), color space (CMYK preferred, RGB accepted with conversion), bleed requirements (0.125" on all sides, text 0.25" from trim edge)
- **Downloadable PDF/AI templates** — pre-sized to each product with bleed guides, safe area markers, and dimension labels. One template per product SKU. Organized in a grid with product name, dimensions, and PDF/AI download buttons.
- **AI prompt guide** — copy-paste-ready prompts for ChatGPT, DALL-E, and Canva AI. Product-specific prompts for tent canopies, backdrops, table throws, flags, and step-and-repeats. Each prompt includes [bracketed placeholders] for business name, colors, and tagline.

#### How it connects to the site:
- Every product page includes a "Need help with artwork?" card below the product tabs, linking to this page
- Product page "Design guide" tab links here
- Footer "Design resources" link in the Support column
- Social content (education pillar) drives traffic here with posts like "3 file prep mistakes we catch every week"

#### Why it works:
Giving clients correct dimensions before they start designing prevents the #1 issue (wrong dimensions/no bleed) at the source. The templates are already built for 70% of products — this phase just makes them accessible on the website instead of emailing them on request.

#### Current template inventory (PDF/AI):

### Phase 2 — Canva Template System
**Timeline:** Month 2 (2–3 weeks of template conversion)
**Cost:** Canva Pro subscription (~$13/month, likely already active)
**Technical complexity:** Low — template design + Shopify button links
**Impact:** Eliminates 70–80% of bad file submissions
**Dependency:** Requires Carlos to convert PDF/AI templates to Canva (needs help)

#### What it includes:

**Template conversion (PDF/AI → Canva):**
- Rebuild each product template in Canva with exact dimensions matching the print spec
- Lock bleed guide layers so clients cannot accidentally move or delete them
- Lock safe area markers (text/logo safe zone) as non-editable background elements
- Set up dimension-accurate artboards — when a client designs in the template, the output is automatically the correct size
- Share each template as a Canva link (anyone with the link can make a copy and edit)

**Guided design flow:**
- Step-by-step walkthrough embedded on the design resources page or as a linked tutorial:
  1. Open the template link for your product
  2. Canva creates a copy in your account
  3. Add your logo (drag and drop)
  4. Choose your brand colors
  5. Add text (business name, tagline, contact info)
  6. Export as PDF Print at 300dpi with bleed marks
- Product-specific guidance for each template (e.g., "Your tent canopy has 4 valances — make sure your logo is placed on each one")

**Brand kit setup guide:**
- Tutorial (video or carousel) teaching clients how to set up a Canva Brand Kit:
  - Upload their logo files
  - Define their brand colors
  - Set their fonts
  - Save as a reusable kit
- Once set up, their brand assets auto-populate in every P&G template they open
- This solves the #2 issue (amateur design) by giving clients professional constraints to work within

**Per-product template links on product pages:**
- Each product page gets a "Design in Canva" button alongside the existing "Need help with artwork?" card
- Button opens the correct Canva template for that specific product at the exact correct dimensions
- Flow: browse product → click "Design in Canva" → design in pre-sized template → export → upload to P&G → order
- Client never opens Illustrator, never guesses dimensions, never forgets bleed

**Export checklist:**
- Visual checklist shown at the export step (on the design resources page and in the Canva template itself as a final slide/page):
  - ☐ Export as PDF Print (not PDF Standard)
  - ☐ Set to 300 DPI
  - ☐ Check "Include bleed marks"
  - ☐ Color profile: CMYK
  - ☐ Review text is inside the safe area (not in the bleed zone)

#### Why it works:
Canva handles the #1 issue (bleed/dimensions) automatically — the template is pre-sized, so the client literally cannot get the dimensions wrong. Locked layers prevent them from moving bleed guides. The brand kit setup solves #2 (amateur design) by giving them professional constraints. The export checklist catches #3 (low DPI) and #4 (RGB vs CMYK) at the final step.

#### Implementation notes:
- Carlos needs help converting the templates — the print specs (dimensions, bleed, safe areas) require production knowledge, but the Canva rebuild itself is mechanical
- Claude can assist by generating the Canva template specs (artboard dimensions, guide positions, layer structure) for each product
- Templates should be version-controlled — when a product spec changes, the Canva template link gets updated
- Consider Canva for Teams if managing many templates becomes unwieldy

### Phase 3 — AI-Powered File Checker
**Timeline:** Month 3 (2–4 weeks of development)
**Cost:** Claude API usage (~$50–100/month at expected volume) + hosting
**Technical complexity:** Medium-high — standalone web app or Shopify embedded app
**Impact:** Eliminates 90%+ of bad file submissions
**Dependency:** Claude API with vision capability

#### Architecture:

**Client-facing upload flow:**
1. **Select product** — client chooses which product they're uploading artwork for. System loads the exact spec requirements for that product (dimensions, DPI, bleed, color space).
2. **Upload file** — drag-and-drop or file picker. Accepts PDF, AI, PNG, JPG, PSD. File size limit: 50MB.
3. **Instant AI review** — system extracts file metadata and sends a rendered preview to Claude vision for quality analysis. Results returned in 10–30 seconds.

**What the AI checks (automated, per-file):**

| Check | Method | Feedback example |
|---|---|---|
| Dimensions match product | File metadata extraction (width/height vs product spec) | "Your file is 1080x1080px but this product needs 36000x36000px (120" at 300dpi)" |
| Resolution (DPI) | File metadata extraction | "Your file is 72dpi — it needs to be 300dpi for print quality at this size" |
| Bleed detection | Dimension comparison (file size vs trim size + bleed) | "No bleed detected — add 0.125" beyond the trim line on all sides" |
| Color space | File metadata extraction (RGB vs CMYK) | "File is RGB — convert to CMYK for accurate color reproduction" |
| Visual quality scan | Claude vision analyzes rendered preview | "Text appears too close to the trim edge — move it 0.25" inward to avoid being cut off" |
| Low-res element detection | Claude vision analyzes rendered preview | "Your logo appears pixelated at print size — upload a vector version (AI/EPS/SVG) for best results" |
| Empty area detection | Claude vision analyzes rendered preview | "Large empty area detected on the left side — is this intentional?" |
| Smart suggestions | Claude vision contextual analysis | "Your design has text on all four valances — consider making the peak logo larger for visibility from a distance" |

**Technical implementation:**

```
Upload flow:
1. Client selects product → system loads product spec JSON:
   {
     "product": "10x10 tent canopy",
     "trim_width_inches": 120,
     "trim_height_inches": 120,
     "bleed_inches": 0.125,
     "min_dpi": 150,
     "preferred_dpi": 300,
     "color_space": "CMYK",
     "accepted_formats": ["pdf", "ai", "png", "jpg", "psd"]
   }

2. File uploaded → server-side processing:
   a. Extract metadata (dimensions, DPI, color space) via ImageMagick/Ghostscript
   b. Render file to PNG preview at screen resolution
   c. Run automated checks against product spec (dimensions, DPI, color space, bleed math)
   d. Send rendered preview to Claude API (vision) with prompt:
      "You are a print production expert reviewing artwork for a [product].
       Product specs: [spec JSON].
       Automated checks found: [results].
       Review this design for: text too close to trim edge, low-resolution elements,
       empty/unused areas, overall composition quality for large-format printing.
       Provide 2-3 specific, actionable suggestions."
   e. Combine automated check results + Claude analysis into a structured response

3. Results displayed to client:
   - Pass/fail status for each check (green check / red X)
   - Plain-English explanation of each issue
   - "Fix it" links to relevant Canva template or design resources page
   - Overall status: "Print-ready!" or "X issues found — fix before ordering"
```

**Result screens:**

| Status | Display | Action |
|---|---|---|
| All checks pass | Green banner: "Your file is print-ready!" | "Proceed to cart" button. File attached to order automatically. |
| Issues found | Red/amber list of issues with plain-English explanations | "Fix it" links per issue. "Upload a new file" button. "Or call us at (844) 883-3308 for help." |
| File unreadable | Error message | "We couldn't read this file. Please upload a PDF, AI, PNG, JPG, or PSD." |

**Integration with Shopify:**
- Option A: Standalone web app (separate URL like files.promongrow.com) linked from product pages
- Option B: Shopify embedded app (appears as a step in the product page or cart flow)
- Option C: Custom Shopify section with JavaScript upload widget + serverless backend (Cloudflare Workers or similar)
- Recommended: Option A for V1 (fastest to build, no Shopify app review process), migrate to Option B if volume justifies it

**What the human (Carlos) still does:**
- Final proof approval before production — the AI catches technical issues, but Carlos reviews for print quality, color accuracy, and production feasibility
- The AI review eliminates 90%+ of the back-and-forth — Carlos only sees files that are already technically correct
- Estimated time savings: from 15–30 minutes per order (current) to 2–5 minutes per order (post-Phase 3)

#### Why it works:
No competitor in the event display space offers AI-powered file review. ExpoPrint has a 3D configurator. Vistaprint has basic template tools. Nobody is checking the client's file and giving instant, intelligent feedback before the order is placed. This is a genuine competitive moat.
