## 🏴 Custom Banners (13oz) — priced by size
**Formula: width (ft) × height (ft) × $5.00/sq ft.** Round any half-foot (e.g. 2.5') **up** to the next whole foot before calculating.
- Example: 4ft × 8ft = 32 sq ft × $5 = **$160**. · 3ft × 6ft = 18 sq ft × $5 = **$90**.

## Quoting rules (quick reference)
1. **On this sheet?** Use the set price. Done.
2. **Not on this sheet / fully custom?** Ask Carlos for the number (trial route-through). Don't guess.
3. **Minimum order $100.** Under that → raise to minimum or add setup/handling.
4. **Discounts** → Carlos approves (Week 1). List price holds otherwise.
5. **Complex branding** (vehicle wraps, channel letters, brand systems) → pitch it, then escalate to Carlos/Proágo.
6. Always close with: **free proof** + **5-day delivery** (4-day on print). *Tu evento, tu marca, hecho bien.*
