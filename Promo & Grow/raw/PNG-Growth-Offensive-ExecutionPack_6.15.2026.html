The step-by-step to stand it all up

Each step is tagged with who does it — Carlos (login/DNS/payment) · Claude (I can do it) · Venus (ongoing). Anything touching credentials, DNS, or payment is yours by design.

Golden rules baked in: cold sends only from promotengrow.com (never the main domain) · warm before you blast · throttle to Venus's capacity · log every lead's source · measure cost-per-closed-deal, not vanity leads.

Part A — Cold Email Setup

A1 · Domain & inboxes Carlos · ~45 min

  • Confirm you own promotengrow.com, separate from main promongrow.com (it is). This is the cold-sending domain — if it takes a hit, invoices stay safe.
  • Set up hosting: Google Workspace (~$6/user/mo) or Microsoft 365.
  • Create 2 sending mailboxes with real human identities: venus@promotengrow.com and team@promotengrow.com — each with a name, photo, signature.
If promotengrow.com was just registered, it needs the full 4–6 week warmup before real sends — no shortcuts.

A2 · DNS authentication (SPF / DKIM / DMARC) Carlos · ~30 min

  • SPF (TXT, host @): v=spf1 include:_spf.google.com ~all
  • DKIM: generate in Google Admin → Gmail → Authenticate email → publish the google._domainkey TXT → turn on.
  • DMARC (TXT, host _dmarc): v=DMARC1; p=none; rua=mailto:dmarc@promotengrow.com; pct=100 — start at p=none, move to p=quarantine after ~2 clean weeks.
  • Hygiene: turn OFF open-tracking pixels; one plain link max from Touch 2 on (tracking now hurts placement).

A3 · Sending tool Carlos acct Claude config

Option C: Apollo for data, dedicated sender for sending. Sign up for Instantly (~$37/mo) or Smartlead (~$39/mo) — both bring warmup, inbox rotation, spam monitoring, one-click unsubscribe, reply detection. Connect both mailboxes; turn warmup ON now.

A4 · Warmup settings Claude

  • Warmup ramp from ~5–10/inbox/day, auto-increase; ~30% warmup reply rate.
  • Real-send caps: 30–35/day per inbox → 2 inboxes ≈ 60/day (inside the 50–75 target).
  • Window: Tue–Thu, 8am–3pm PT; random 60–180s delays.

A5 · Build the list in Apollo Claude · data-only

  • Geo: LA + South Gate, Lynwood, Huntington Park, Bell, Downey, East LA, Santa Ana radius.
  • 1–50 employees; restaurants/food, religious orgs, events/party, auto, retail, personal care, real estate.
  • Titles: Owner, Founder, President, Manager, Marketing. Verified email required. First batch ~300–500.
  • Export → import to cold tool → re-verify (keep bounces < 2%). Don't send from Apollo — data lane only.

A6 · Load the sequence Claude

Load the 3-touch bilingual sequence; map {{first_name}}, {{business}}, {{city}}, {{product_angle}} (by industry). Touch 1 Day 1 (no link) → Touch 2 Day 3 → Touch 3 Day 7. Auto-stop on reply; suppress unsubscribes.

A7 · Pre-launch deliverability QA Claude

Seed/inbox-placement test — aim ≥ 80% inbox before scaling. Confirm replies route to Venus + tag Source = Cold Email.
