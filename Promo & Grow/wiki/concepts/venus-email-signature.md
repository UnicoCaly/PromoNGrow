## Install (Carlos / Venus lane)
1. Open the chosen `.html` file in Chrome.
2. Click **Copy signature** (or select the white card and Cmd/Ctrl + C).
3. Gmail: ⚙ → See all settings → General → Signature → Create new → paste → **Save Changes**. (Apple Mail / Outlook web: the same paste flow — exact steps are printed in each file.)
4. Send a test to yourself; check it on both desktop and phone.

Recommended default: **Classic** or **Banner** for Venus's outbound; **Card** if she wants the most compact look.
