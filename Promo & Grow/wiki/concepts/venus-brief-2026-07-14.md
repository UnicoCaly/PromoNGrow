## 4. The neon / color-gamut production caveat

Shadi wants a **neon-yellow (bright, near-fluorescent) background** on the window vinyl. Printed vinyl **can't reproduce true neon** — print is CMYK (P&G runs 6-color, CMYK + light cyan + light magenta), and neon/fluorescent is outside that gamut; a printed "neon" comes out muted/"dirty," not bright. Screens (RGB) show a wider gamut, so logos/refs designed on screen often carry near-neon colors that don't print as seen.

- **To actually hit the neon:** a different process — a **solid specialty/fluorescent vinyl** as the background (two-part build: install the colored film, then the messaging on top), an **~$800 upcharge** and a scope change.
- **Recommendation (reached):** steer Shadi to her **existing brand colors** (her site/branding has no neon) for cohesion — and because a *printed* neon would disappoint her anyway. She's been negotiating hard on price, so the +$800 is unlikely.
- Carlos flagged this as broadly important: *"people that bring neon colors — neon colors don't print,"* so it's a recurring conversation as file volume grows. Full production knowledge + client scripts → [[print-color-and-material-limits]].
